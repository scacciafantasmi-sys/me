WaveCraft
Clic su una cella per attivare/disattivare uno step. "Piano" apre l'editor completo per quella traccia.
Seleziona una traccia dal Channel Rack (pulsante "Piano")
Clic su una cella vuota per piazzare il pattern selezionato, clic su un blocco per rimuoverlo.
WaveCraft è una piccola DAW originale, interamente client-side: un unico file HTML, nessun server, nessuna dipendenza esterna, nessun asset audio caricato — ogni suono (cassa, rullante, hi-hat, clap, synth, riverbero) è generato proceduralmente via Web Audio API. Non è un clone di alcun software commerciale: interfaccia, motore audio e preset sono un progetto originale ispirato al flusso di lavoro "channel rack + piano roll + playlist + mixer" comune a molte DAW moderne. Il progetto si salva automaticamente nel browser (localStorage) ed è esportabile/importabile come file JSON, sullo stesso principio degli altri progetti di questo repository.
